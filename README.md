# DMIT 库存：为什么总是 Out of Stock、什么时候补货，以及当前还能下单的洛杉矶 AS3 全系套餐

点进 DMIT 官网，看中的套餐旁边挂着 "Out of Stock"，这在 VPS 圈里基本算日常。搜「DMIT 库存」的人，想知道的其实就三件事：现在到底有没有货，下一轮补货大概什么时候，以及实在没货还能买什么。

先把这三件事拆开说。

## 缺货不是意外，是 DMIT 的销售策略

DMIT 成立于 2017 年，做的是洛杉矶、香港、东京三个机房的 KVM VPS。它的卖点集中在线路：自建骨干网，直签国内三大运营商，CN2 GIA、AS9929、CMIN2 这几条线路的带宽是实打实买来的，公开资料里提到 CN2 GIA 带宽 40Gbps、9929 与 CMIN2 各 20Gbps。

所谓「不超售」，落到销售环节就变成：一批硬件上架多少台就卖多少台，卖完关单，等下批硬件到位再开。好处是邻居之间不互相抢资源，坏处是库存常年处在「刚补完就开始紧张」的状态。

另一层限制来自 IP。此前 TYO.AS3.Pro 长期售罄时，客服给出的解释就是 IP 资源不足——带宽配额和 IPv4 都不是想加就能加的。

销售窗口有多短？香港 Pro 的 VICTORIA（年付 $298.88）有过三小时卖光的记录；特价机型的窗口期通常只有 2 到 12 小时。这也就解释了为什么很多人是「刷到有货 → 犹豫一下 → 再点进去就没了」的循环。

## 查库存的几个入口，准确度不一样

最准的永远是官网自己：商品页会直接标注库存状态，售罄的 SKU 页面通常还带一个到货提醒开关，填一个你每天都看的邮箱，这是官方渠道里唯一比别人快半步的地方。想直接对着下单页看，可以 [👉 打开 DMIT 商品页确认实时库存](https://www.dmit.io/aff.php?aff=12046)。

其次是第三方库存监控站。社区里流传过的有几个，比如 stock.qixi.me、stock.dmitea.com，还有 VPS1111 那种限量版监控大屏，以及开源的 Costinel、Jito 这类自建工具。这类服务的优点是轮询频率高、能邮件或 Telegram 推送，缺点是它们本身就依赖 DMIT 页面结构，官网改版或防爬一加强就会集体失灵——社区里就有过监控站「库存状态全变成未知」的反馈。

再往下是 Telegram 补货频道和 Nodeseek、V2EX、LINUX DO 这类论坛的帖子。优点是有人帮你看，缺点是看到消息的时候，便宜档位大概率已经被自动化脚本扫过一轮了。

一句话排序：官网页面 > 邮件到货提醒 > 第三方监控 > 论坛和群。

## 补货大概什么时候来

社区多年蹲守总结出来的规律并不复杂，只是不保证：

- **大促节点**。黑五、圣诞元旦、春节、618、双十一，DMIT 基本都会放一批限量特价加常规货。社区里流传的一句经验是「电信用户闭眼买美西 Pro，移动联通选美西 EB」，说的就是这个节点的抢法。
- **季度末或月末**。退款释放和到期回收的机器资源会重新上架，量不大。
- **平台升级之后**。DMIT 给套餐做配置升级时，往往会同步开放新库存。比如洛杉矶 AN4 硬件资源耗尽下架后，AN5 平台紧接着上线并开放月付、季付。
- **没有理由的随机放货**。这条最气人，但确实存在。

反过来说，也有明确的「没货期」。今年 5 月 DMIT 曾突发暂停所有产品销售，原因是洛杉矶机房的机柜空间、电力和存储集群没到位；在那之前，社区里已经有人在说「连 LAX T1 这种无优化的机器都断货了」。

## 三条线路，按运营商挑就行

**电信用户优先 Pro。** 去程回程都压在中国电信 CN2 GIA 上，这是 Pro 溢价的主要来源。轻量站点选 TINY（$10.90/月，2GB 内存 + 1TB 流量）基本够用；流量上到 3TB 再看 STARTER。

**联通和移动用户优先 EB。** 同价位下 EB.TINY 给到 1500GB 流量和 2Gbps 端口，比 Pro.TINY 的 1000GB / 1Gbps 宽一截。9929 对联通、CMIN2 对移动，都是各自链路上更直接的选择。

**不面向国内的业务直接看 T1。** $36.90 一年的 WEE 在 DMIT 整个产品线里属于价格洼地，4Gbps 端口配 1TB 流量，跑备份、镜像同步、海外 API 足够。

如果你的使用场景是「大部分流量给海外用户，偶尔国内也要访问」，T1 + 一条便宜的国内中转，通常比硬上 Pro 更划算。

## 下单前值得先弄清楚的几件事

**退款条件。** 购买不超过 3 天、且流量使用不超过 30GB，可以全额退款（扣除支付网关收取的交易费用）；购买不超过 30 天的，按剩余价值部分退款。所以「买回来先测」这条路是走得通的，前提是别一上来先跑满流量。

**免费换 IP 是有门槛的。** 常见说法是每个自然人可以每 15 天免费换一次，实际条件包括：实例开机满 7 天、距上次换 IP 至少 15 天、ICMP 和 TCP 全端口不可达、剩余服务期不少于 7 天。不是「看着不顺眼就能换」。

**付款方式。** 支持支付宝、微信、PayPal。走支付宝还有个额外好处——退款时不产生网关手续费，进退都轻一些。

**流量是双向计费的。** 入站出站都算，高流量业务在选 TINY 档位时要额外留意。好在超量不停机，只会把带宽压到 4Mbps 到 10Mbps。

## 想要的套餐没货了，怎么办

按优先级排，大致是这么几条路：

1. **往上跳一档**。高配档位经常还有货，因为需求在价格上就筛掉一批人。预算够就直接升。
2. **换线路**。Pro 缺货时 EB 往往还在，EB 也缺就看 T1。
3. **换机房**。洛杉矶是 DMIT 相对最容易有货的机房，香港和东京因为回国线路成本高、带宽配额小，售罄是常态。
4. **挂监控等下一轮**。把官网的到货提醒和第三方监控一起挂上，同时盯 TG 补货频道。要有心理准备，等四到六周才抢到目标档位的情况并不少见。

一个实用建议：如果是正式业务，别把「等特价机」当成计划的一部分。特价机（WEE、MALIBU、PalmSpring、Irvine 这些）本身属于闪购性质，窗口短、库存少，当成抽奖更符合实际；正价套餐才是那台「随时能买到、价格贵一截」的保底方案。

## 几个常被问到的问题

**库存监控站显示有货，点进去却是缺货，为什么？**
监控是轮询抓取的，本身有延迟，而且批量下单往往是并发的。看到通知后立刻下单，仍然可能刚好卖完。只能当成提醒，不能当成保证。

**特价机还会再放吗？**
社区里的判断偏保守。有人从去年圣诞节等到现在，一直没等到新的特价批次；也有观点认为硬件短缺在短期内不会缓解。官方没有给出确定的时间表，所以任何「下个月一定补货」的说法都不可信。

**AS3 和 AN5 差在哪？**
平台代次。AS3 是 AMD EPYC 7003 系列，AN5 是更新的 EPYC 9005，性能更强，价格也更高。AN4 已经因硬件资源耗尽下架，目前这两代是主要选择。对只跑隧道或代理的用户来说，CPU 代次的差别几乎感受不到。

**买之前能做点验证吗？**
可以。DMIT 提供 Looking Glass 入口，按机房分线，洛杉矶就有 lax-pro、lax-eb、lax-t1 三个。先 ping、trace、测下载，确认线路符合预期再下单，比事后申请退款省事得多。

库存这件事，说到底就是 DMIT 用它换来了不超售。值不值得为它蹲货，取决于你的项目能不能等。不能等，就 [👉 现在去 DMIT 挑一台现货](https://www.dmit.io/aff.php?aff=12046)；能等，把到货提醒挂上，剩下的交给运气。
